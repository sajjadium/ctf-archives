# Interacting with the Server

To interact with the server, send a JSON request in one of the formats below. Specify the `operation`, the `source` array(s), the indices, a `const` (if applicable), and the `destination` array and index where the result is stored.
x,y are table with size of 100
```json
// Add x[2]=x[0]*x[1]
{"operation":"add","source":["x","x"],"source_index1":0,"source_index2":1,"destination":"x","dest_index":2}

// Multiply y[2]=x[0]*y[1]
{"operation":"mult","source":["x","y"],"source_index1":0,"source_index2":1,"destination":"y","dest_index":2} 


// Add constant y[2]=x[0]+10
{"operation":"add_const","source":"x","index":0,"const":10,"destination":"y","dest_index":1}

// Multiply constant x[5]=y[1]+5
{"operation":"mult_const","source":"y","index":1,"const":5,"destination":"x","dest_index":5}
```
