Two instruments crossed the same loop, yet their readings no longer align. The recovery terminal accepts one rotation index. Determine it from the instrument's enormous sealed tape. The archive will make your machine finish the restoration before revealing the record.

Run ./monodromy beside capsule.bin, then use python3 seal.py INDEX to open the record. The executable is Linux x86-64 (chmod +x monodromy after download if needed). The seal helper requires Python 3.10+, argon2-cffi, and cryptography. Plan for several GiB of RAM.

Files: monodromy, capsule.bin, seal.py Flag Format: isfcr{...}
