BRIEFING
During Operation Dawn, Ash Army signals engineers tested relay firmware on a small register machine they call the golem. A coalition team captured its specification and a set of worked examples. The machine's audit service runs 100 programs, each with an input tape, and checks your answer against what the golem would print, exactly, quirks included. One wrong answer closes the session.

Connect to the audit service, build an interpreter that behaves as the specification and the examples describe, and answer every program.

Flag format: CSCTF{...}
