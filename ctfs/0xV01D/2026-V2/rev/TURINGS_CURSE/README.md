If you gaze long into the void, the void gazes back.

Inside this binary sleeps a single true name. Speak it, and the core unseals.

But the void is generous with lies. It has carved a hundred false names into its walls, and it whispers easy answers to anyone impatient enough to listen. There are no shortcuts here — no string that saves you, no brute force that outlives the dark. The only way out is to understand exactly how the void transforms what you feed it, and walk that path backwards.

Many will find a flag. Almost all of them will be wrong.

Rule: reverse it properly. The obvious answer is never the answer.
