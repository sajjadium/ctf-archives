Cryptography
The Commons keeps its Python snakes in a vivarium. Each one is sealed in an enclosure, safely separated from the vault where their food is stored.

Or so the keepers thought. One particularly sneaky snake slipped through the GPG socket connecting its enclosure to the vault.

Run /flag and the vault will return an encrypted message. The public key is available at /flag.pub; the rest is history.

Follow the snake and recover the plaintext flag.
