Every citizen in the Commons registers a handle before they can act. A short list of names is reserved for the Archive's own keepers, and the directory won't let anyone claim one outright.

The Archive doesn't consult the directory's list. It reads whatever name is presented and decides for itself whether it recognizes an archivist — kind enough not to be thrown off by unusual spelling.

The citizen registry's source is attached for audit.
