Три кривые над тремя полями. Одна открыта, одна под замком, одна — приманка. Чтобы добраться до флага, придётся пройти их по порядку: каждая следующая откроется только после того, как падёт предыдущая. Стандартные инструменты здесь бессильны — нужны те, что лежат глубже.

EN

Three curves over three fields. One is open, one is locked, one is bait. Reaching the flag means clearing them in order: each one unlocks only after the previous has fallen. Off-the-shelf tools won't help here — you'll need the ones that lie deeper.
